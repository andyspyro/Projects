# Dating Application Database Team Project

> **Type:** Three person classroom database application  
> **My role:** Mock project manager and team coordinator  
> **Status:** In progress

My group chose a fictional dating and matchmaking application for the class database project.

This is not a solo project. There are three people on the team, and my assigned role is the mock project manager. I help keep the group work organized while also contributing to the database side.

## What I can verify

The course project requires a team to design and develop a database application. The class work covers ER and EER modeling, the relational model, SQL, query work, normalization, physical database design, project phases, peer review, and a final group submission.

Our chosen application theme is the dating app.

## My role

I handle work such as:

* organizing the project plan
* helping divide tasks between three people
* tracking project phases and due items
* reviewing pieces before group submission
* keeping names and database decisions consistent
* helping combine separate work into one final submission
* coordinating report and presentation work
